# packages
Automatically make a list of the DataSHIELD packages using info from CRAN and GitHub.

If there are any packages missing, please add them to the list in `/packages_list.csv` via a pull request, or submit an issue. 

## DataSHIELD functions metadata
Based on the entries in `/packages_list.csv` metadata from DataSHIELD functions are extracted and stored in the `/datashield_functions_metadata.json` file.
